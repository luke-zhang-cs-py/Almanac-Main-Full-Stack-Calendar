Almanac
the slot engine · browser build

This is the slot engine only — not the booking platform. Almanac is JWT sign-in over a relational database, transactional email and a background reminder thread, and none of that can run in a browser tab. What can is the part that is pure computation: turning a provider's recurring weekly hours, their one-off blocks and their existing bookings into the list of slots a guest may actually book. That is what this page is, and it is all it is.

There is no account, no database, and nothing is saved. Every row you add below lives in this tab and is gone when you close or reload it. Nothing is uploaded and no request leaves the page. You cannot book any of the slots it shows you — there is nobody to book them with.

js/slots.js is a port of domain/calendar_logic.py, and tools/build_static.py runs the two against each other in a real browser over a matrix of scenarios before publishing this page. It refuses to write a single file if they disagree about one slot. Source, and the Flask app the engine belongs to →

What the provider has set

The three tables the engine reads. Change any of them and the board on the right recomputes.

Start from

Weekly opening hours

Recurring, by weekday. A window is a start, an end and the length of one slot; a day may have several, and a day with none is simply not open.

One-off blocks

Time taken out of a single date. Leave both times empty for a whole day off — that is what a null pair means in the blocked_slots table, and the engine reads it that way.

Existing bookings

The engine's filter is status = 'confirmed', so only a confirmed appointment is busy. Cancelling one frees its slot again, which is the whole point of cancelling it; a completed one frees it too, which is almost always moot because a completed appointment is in the past.

What a guest may book

Computed here, in this tab, by the same rules the Flask app applies.

The question

The clock is a control because it is part of the answer: a date in the past offers nothing at all, and today offers only what has not started yet. A slot beginning this very minute is already gone — by the time anyone confirmed it, it would have begun.
