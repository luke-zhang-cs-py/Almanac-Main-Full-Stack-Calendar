The single-role branch: appointment booking, before Almanac grew a planner and a wallet

JWT auth over three roles — client, provider, admin — a free-slot engine that turns recurring hours into bookable times without ever double-booking, automatic email that fires exactly once, and coffee chats: an invite that produces a booking without the guest ever making an account. This branch is where that pattern was built and audited twice before Almanac-Main added the planner import and multi-currency wallet on top of it.

Repository Open app (local) Architecture

What a free slot is, and what it has to survive

calendar_logic.py turns a provider's recurring weekly hours, their one-off blocked dates and their existing bookings into the list of times a client may actually pick, for any date.

    Automatic email, sent exactly once

    Welcome, booking confirmation, cancellation, completion, and a 24-hour reminder — none of them need a button pressed.

    Delivery happens on a background thread, so a slow mail server never slows down a booking.
    WhenWho gets mailed

    Nobody is mailed twice

    A unique index on email_log (appointment_id, kind, recipient) is the source of truth rather than a flag somebody remembers to set — one of the bugs the second audit pass found was exactly this: a host receiving two emails for one booking, from two code paths that both thought they were the only sender.

    Nothing blocks, and nothing is lost

    mailer.send() writes a row and hands the message to a worker thread; the booking request returns immediately. With no SMTP_HOST set, the message prints to the terminal instead of sending — which is also how a Unicode en dash in the details block once raised UnicodeEncodeError under a narrow console and got logged as a failed send for a message that was never actually attempted.

    Coffee chats: an email that produces a booking

    The reverse of the usual direction. You send someone an invite, they click the link, they see your real availability, they pick a time — and they never make an account.
